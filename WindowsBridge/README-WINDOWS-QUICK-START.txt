ETS2 CarPlay Windows 설치·실행 안내
====================================

Visual Studio, .NET SDK, CMake를 설치할 필요가 없습니다. 준비된 Windows ZIP과 ETS2만 있으면 됩니다.

준비물
------
- Windows 10/11 64비트, Steam ETS2
- iPad에 설치된 ETS2 CarPlay 앱
- PC와 iPad를 연결할 같은 공유기

PC에 Wi-Fi가 없어도 됩니다. PC는 랜선으로 공유기의 LAN 단자에 연결하고 iPad는 같은 공유기의 Wi-Fi에 연결하세요. 이 연결에는 인터넷이 필요하지 않습니다. 다만 Windows ZIP을 처음 받으려면 인터넷이 필요합니다. USB 케이블만으로 Windows PC와 iPad 앱을 직접 연결하는 기능은 없습니다.

Windows PC에서 인터넷을 쓸 수 없다면 Mac이나 인터넷이 되는 다른 기기에서 GitHub Actions의 Windows ZIP을 받은 뒤 USB 메모리에 복사해 Windows PC로 옮기세요. Windows PC에서는 ZIP 압축을 풀고 아래 설치를 진행하면 됩니다. 다운로드와 파일 옮기기는 한 번만 하면 됩니다.

처음 한 번 설치
--------------
1. GitHub 저장소의 Actions > Build Windows install bundle에서 가장 최근 초록색 완료 실행을 엽니다.
2. 실행 화면 아래 Artifacts > ETS2CarPlay-Windows를 눌러 ZIP을 내려받고, 파일을 마우스 오른쪽 버튼으로 눌러 [모두 압축 풀기]를 선택합니다.
3. ETS2와 브리지 검은 창이 켜져 있으면 둘 다 종료합니다. 압축을 푼 폴더에서 Setup-ETS2CarPlay.bat을 두 번 누릅니다. 나중에 업데이트할 때도 기존 브리지를 먼저 닫으세요.
4. 기본 Steam 위치에서 ETS2를 찾으면 [예]를 누릅니다. 못 찾거나 다른 드라이브에 설치했다면 폴더 창에서 ETS2의 Euro Truck Simulator 2 폴더를 고릅니다. 선택할 폴더 안에 bin\win_x64가 있어야 합니다.
5. Windows 권한 확인 창에서 [예]를 누릅니다. 설치가 끝나면 바탕 화면에 [ETS2 CarPlay 브리지] 바로 가기가 생깁니다.

매번 ETS2를 할 때
----------------
1. PC와 iPad가 같은 공유기 네트워크에 있는지 확인합니다. PC를 랜선으로 연결해도 됩니다.
2. ETS2를 켜기 전에 바탕 화면의 [ETS2 CarPlay 브리지]를 두 번 누릅니다. 검은 창을 닫지 말고 게임 중 계속 열어 둡니다.
3. Windows 방화벽이 물으면 [개인 네트워크]에만 허용합니다. 인터넷에 공개하지 마세요.
4. iPad에서 설정 > ETS2 연결을 엽니다. 첫 연결 때만 브리지 창의 IPv4 주소와 6자리 코드를 입력합니다. 주소가 여러 개면 iPad와 같은 공유기에 연결된 주소를 씁니다. 127.0.0.1은 쓰지 않습니다.
5. 주소와 코드는 각 행을 눌러 iPad 앱 안 숫자판으로 입력합니다. 포트는 8765 그대로 둔 뒤 [연결 또는 페어링]을 누릅니다. iPad 키보드는 필요하지 않습니다.
6. ETS2를 실행하고 프로필을 불러와 실제 운행을 시작합니다.

첫 페어링 뒤에는 주소와 인증이 저장됩니다. 이후는 PC에서 바탕 화면의 [ETS2 CarPlay 브리지]만 열면 자동 재연결됩니다. 다시 코드를 입력할 필요가 없습니다.

Wi-Fi가 안 될 때
----------------
- PC가 Wi-Fi를 지원하지 않으면 랜선으로 같은 공유기 LAN 포트에 연결합니다. iPad는 그 공유기의 Wi-Fi에 연결합니다.
- 공유기 인터넷이 끊겨도 공유기와 내부 네트워크가 켜져 있으면 PC와 iPad는 연결할 수 있습니다.
- 게스트 Wi-Fi는 기기 사이 연결을 막을 수 있으므로 일반 Wi-Fi를 쓰세요.
- 랜선과 Wi-Fi 어댑터가 모두 없다면 USB Wi-Fi 어댑터를 PC에 꽂아 같은 네트워크에 연결할 수 있습니다.

페어링을 다시 해야 할 때
-----------------------
1. 실행 중인 ETS2 CarPlay 브리지 검은 창을 닫습니다.
2. Windows 시작 메뉴에서 ETS2 CarPlay > ETS2 CarPlay 페어링 복구를 실행합니다.
3. 새 코드가 표시되면 iPad 설정 > ETS2 연결에서 예전 페어링을 삭제하고 새 코드를 입력합니다.

문제 해결
---------
- 연결 실패: PC와 iPad가 같은 공유기에 연결됐는지 확인하고, Windows 방화벽은 개인 네트워크에서 허용합니다.
- 연결되지만 속도·목적지가 비어 있음: ETS2에서 프로필을 불러와 실제 운행을 시작합니다. 메인 메뉴에는 주행 데이터가 없습니다.
- 선택한 게임 폴더가 잘못됨: Steam 라이브러리에서 ETS2를 마우스 오른쪽 버튼으로 눌러 관리 > 로컬 파일 보기를 선택하고, 열린 Euro Truck Simulator 2 폴더를 고릅니다.
- 연결 조작 버튼: 기본 키 설정은 꺼져 있습니다. 직접 키를 설정하기 전까지 원격 조작 명령을 보내지 않습니다. 키를 바꾸려면 %LOCALAPPDATA%\ETS2CarPlay\controls.json을 메모장으로 편집하고 브리지를 다시 실행하세요.
